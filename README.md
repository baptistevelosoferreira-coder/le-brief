# Le Brief — page d'inscription

Page d'inscription à **Le Brief**, la newsletter sport du matin : les infos les plus
importantes de tes sports, les scores de la veille et le programme du jour.

- `index.html` : la page (un seul fichier, aucune installation nécessaire).
- Publiée avec GitHub Pages : **Settings → Pages → Branch `main` / dossier `/ (root)`**.

Tant que `URL_INSCRIPTION` (dans `index.html`) est vide, la page est en **mode démo** :
le formulaire fonctionne mais les inscriptions ne sont pas enregistrées. Pour les
enregistrer dans un Google Sheet, voir `inscription/README.md` dans le dépôt de la newsletter.
